Part 1: Nested Loops (Visiting Every Cell)

👉 INSTRUCTION: Click "Next Step" on the loop visualizer below, then complete Task 1.

To visit every cell in a 2D list, put one for loop inside another. This is called a nested loop.

  • The outer loop picks each row (top to bottom).
  • The inner loop moves across every column in that row (left to right).
grid = [
    [4, 7, 2],
    [9, 1, 5]
]

for row in range(len(grid)):              # outer loop: row = 0, then 1
    for col in range(len(grid[0])):       # inner loop: col = 0, 1, 2
        print(grid[row][col])

Part 3: Row-by-Row Totals (Exam Favourite)

👉 INSTRUCTION: Notice where row_total = 0 is placed below, then complete Task 3.

In Edexcel Paper 2 questions, each row often represents one player or one student, and you must calculate a separate total for each row.

💡 Crucial Detail: Set row_total = 0 inside the outer loop (just before the inner loop). That way it resets to zero for every new row!
# Each row is one player's 3 round scores
scores = [
    [10, 12, 8],    # Player 0 → total 30
    [15, 10, 15]    # Player 1 → total 40
]

for r in range(len(scores)):
    row_total = 0                          # resets for each player!
    for c in range(len(scores[0])):
        row_total = row_total + scores[r][c]
    print(f"Player {r}: {row_total}")
